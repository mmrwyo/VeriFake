# Input data provenance

The experiments used existing labeled Kaggle Fake News and ISOT news collections. ChatGPT assistance with acquisition/code does not establish that the underlying news articles were generated by ChatGPT.

The original notebook records these acquisition mirrors:

- train.csv: https://huggingface.co/datasets/Shiv-Pal/Fake_Real_News/resolve/main/train.csv
- Fake.csv: https://huggingface.co/datasets/koliskos/fake_news/resolve/main/Fake.csv
- True.csv: https://huggingface.co/datasets/koliskos/fake_news/resolve/main/True.csv

Original source attribution:

- Kaggle Fake News competition: https://www.kaggle.com/competitions/fake-news
- University of Victoria ISOT dataset page: https://onlineacademiccommunity.uvic.ca/isot/datasets/
